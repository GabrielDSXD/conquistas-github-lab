# Laboratorio de conquistas do GitHub

Repositorio de teste de GabrielDSXD para praticar issues e pull requests.

## Exercicios

- Quickdraw: abrir e encerrar uma issue em menos de cinco minutos.
- YOLO: integrar um pull request de documentacao sem revisao.
- Pull Shark: abrir e integrar dois pull requests.

As atividades deste laboratorio sao exercicios. O GitHub decide a concessao das conquistas e a atualizacao do perfil pode nao ser imediata.

## Outras conquistas

- Pair Extraordinaire: requer coautoria real em um commit integrado por pull request.
- Galaxy Brain: requer respostas aceitas em discussoes.
- Starstruck: requer estrelas de outras pessoas (o guia indica 16 no primeiro nivel).
- Public Sponsor: requer patrocinio pelo GitHub Sponsors.
- Pro, Campus Expert e badges de seguranca: dependem de assinatura, programas ou contribuicoes qualificadas.
- Mars 2020 Contributor e Arctic Code Vault Contributor: conquistas historicas encerradas.
- Heart On Your Sleeve e Open Sourcerer: listadas como experimentais no guia; nao ha garantia de disponibilidade.

Nao sao utilizadas contas falsas, estrelas compradas, coautorias inventadas ou contribuicoes em repositorios de terceiros.
