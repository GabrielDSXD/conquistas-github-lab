## Pendencias que exigem participacao externa

- Pair Extraordinaire: contribuicao em coautoria real, integrada por pull request.
- Galaxy Brain: duas respostas aceitas em Discussions, conforme o guia.
- Starstruck: estrelas de outras pessoas; o guia indica 16 no primeiro nivel.
- Public Sponsor: patrocinio de projeto elegivel pelo GitHub Sponsors, com pagamento.
- Pro, Developer Program Member, Campus Expert e badges de seguranca: requisitos dos respectivos planos, programas ou contribuicoes qualificadas.
- Open Sourcerer: listado como experimental no guia, sem disponibilidade garantida.
- Mars 2020 Contributor e Arctic Code Vault Contributor: conquistas historicas encerradas.
